# Tune Toy release notes

Slice 1 of howl. She says or types her lines, fixes the bits, taps a tune for each line over a beat, and plays the song back.

## Install on Windows

1. Download `howl-setup.exe` from the "Tune Toy (latest build)" release.
2. Run it. It installs for this user, with no admin needed.
3. If Windows warns about an unknown app, choose More info, then Run anyway. The app is unsigned.

## In this build

- Home, New song, Say it all with local dictation, Your lines with syllable fixing and read-aloud
- Tune: tap, hold, slide, Backspace, block editing, Tidy timing, Same tune as, Again, Next line, Play song
- Moods, speed, sounds, 5 and 7 notes, octave arrows, Settings, the keyboard map
- Autosave to `.howl` files in Documents, undo and redo
- No network at runtime
